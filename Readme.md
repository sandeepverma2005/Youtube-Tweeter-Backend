# YouTube-Tweeter Backend

A robust backend application built with Node.js and Express.js, designed to handle core functionalities for a video-sharing and microblogging platform. It manages user authentication, video/tweet processing, and data persistence with MongoDB.

## Features
* Secure User Authentication & Authorization (JWT)
* Video Upload & Tweet Management
* Like, Comment, and Subscription Systems
* Tweeter-style post creation and feeds

This is backend with javascript
